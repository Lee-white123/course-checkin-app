## Users

Primary users are parents and teachers using mobile phones in a tutoring-center context. Parents need to register, log in, and later review course arrangements with low friction. Teachers need to register, log in, and enter the system to manage class check-in work. Desktop use for parents and teachers is secondary. Administrators use the system less often from this surface; their login path should remain available but not dominate the page.

## Product Purpose

The system manages course scheduling, class-hour consumption, teacher check-ins, parent viewing, and administrator operations for a middle-school tutoring class. Success means users can identify the correct role, complete login or registration confidently, understand validation errors, and enter the right portal without needing technical help.

## Brand Personality

Clear, trustworthy, professional. The interface should feel like a serious education service: calm enough for parents, efficient enough for teachers, and restrained enough for administrative use.

## Anti-references

Do not make the product feel like a marketing landing page, a decorative education brochure, or a cold enterprise dashboard. Avoid over-styled gradients, generic AI-card layouts, playful cartoon decoration, excessive motion, and dense administrator-first language on login and registration surfaces.

## Design Principles

- Mobile-first for parents and teachers: the most common path should be comfortable on a phone.
- Trust before decoration: visual choices should make the service feel reliable and easy to understand.
- One clear next action: each screen should make the primary action obvious without hiding secondary paths.
- Errors should guide correction: validation copy should appear close to the field and say exactly how to fix it.
- Keep the system familiar: use standard form controls, predictable role selection, and consistent feedback.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Support keyboard focus, visible error states, readable mobile spacing, and reduced motion. Avoid relying on color alone for validation or account status. Chinese copy should be plain, specific, and understandable to non-technical parents.
