# 课时消除管理系统（本地简易版）

这是根据需求文档先做出的第一版本地网页系统。它暂时不包含登录验证，重点验证核心流程：

1. 后台新增老师、学生、课程。
2. 后台进行课程编排。
3. 老师端查看自己的课程，并打卡消课。
4. 家长端查看学生课表和历史上课记录。
5. 所有数据保存到本地 SQLite 文件。

## 运行方式

在 Windows 上打开 PowerShell，进入项目目录：

```powershell
cd D:\project\course-checkin-app
python app.py
```

看到下面这类提示后，在浏览器打开：

```text
http://127.0.0.1:8000
```

## 数据保存位置

第一次运行时会自动创建 SQLite 数据库文件：

```text
D:\project\course-checkin-app\data\attendance.db
```

如果想重新体验初始演示数据，可以先停止程序，然后删除这个数据库文件，再重新运行 `python app.py`。

## 当前已实现

- 概览统计：老师数量、学生数量、待上课、已消课、购买课时、剩余课时。
- 后台管理：新增老师、学生、课程。
- 课程编排：选择学生、老师、课程、星期、时间段、课时和备注。
- 老师消课：选择老师，查看课程，填写课堂反馈和错题备注，完成打卡消课。
- 家长查看：选择学生，查看课程表和历史上课记录。

## 后续建议开发

- 登录和角色权限：管理员、老师、家长分别登录。
- 编辑和禁用：老师、学生、课程、排课记录的编辑/删除/启用/禁用。
- 图片上传：老师上传错题图片或课堂照片。
- 课时购买记录：区分充值课时、赠送课时、退费课时。
- 数据导出：导出 Excel，用于财务和教务核对。
- 云端部署：上线后再考虑服务器、域名、HTTPS、备份。
